# Mechanical

CAD captures of the robot: the frame, the drive modules and the electronics
stack.

| File | What it shows |
|---|---|
| `image (1..5).png` | Views exported from the CAD |

The frame mixes 3D-printed structural parts with aluminium plates; each drive
module carries a mecanum wheel on a stepper through a printed gearbox. The
result, next to the CAD model, is the repository hero photo:
[`../Docs/assets/charara-robot.jpg`](../Docs/assets/charara-robot.jpg).

The geometry that matters to the software - body size, clearance margin,
half-diagonal - is configured in the console (see
[`../Docs/04-console-guide.md`](../Docs/04-console-guide.md) section 8).
